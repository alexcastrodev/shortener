# Security policy

Kurz is an open source project with a public demo at kurz.fyi.

## Reporting a vulnerability

Please do **not** open a public issue or pull request for a security problem.
Use GitHub's private reporting: **Security → Report a vulnerability** on this repository.

Include what you found, the request or steps that reproduce it, and the impact. Never include
real personal data in a report. You can expect an acknowledgement within a few days.

## Scope

The API (`api.kurz.fyi`), the web app (`kurz.fyi`) and the code in this repository. Out of scope:
volumetric DoS, social engineering, and findings that need a compromised device or account.
